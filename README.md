头像沿用V1角色参考图，改为大头和少量肩膀，简化了细纹与衣服装饰。`preview_native_sizes.jpg` 展示48、56像素原尺寸在浅色和深色底上的效果；`preview_portraits.jpg` 可查看全部状态；`preview_permission.jpg` 是权限引导预览。预览底色和文字不在正式透明PNG中。

休息与睡着分别处理：小克休息时花开、睡着时花合苞；哈基米睡着时耳朵耷拉、尾巴尖盖脸；小鱼睡着时抱鲸尾、嘴边有一粒米。重启中与重启完成使用单独图像。

所有PNG使用真实透明背景。外圈圆框、投影、小红点、倒计时数字和字幕条由App绘制，素材中未加入这些元素。权限引导中的手机、头像贴片和拨动开关是该插图的道具。

人物由生图工具制作，再按已获允许的方式拆图、等比缩放和补透明画布。`manifest-overlay.json` 包含每张图的尺寸、透明状态及SHA-256。
