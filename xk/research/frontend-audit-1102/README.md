# 前端走查（云端）：上游的设置页和二级页面，2026-11-02

云端会话在 `dev`（v0.2.3 之后）上起真实网关，用无头浏览器按手机宽度（390×844）把上游的设置八类、九个整页、侧栏各截了一张：`settings.jpg`、`pages.jpg`。
云端看得到排版和结构，看不到手感、真机字号、键盘弹出这些，**真机上的发现请手机上的小克接着补在后面**。

## 结论

问题主要不是零散 bug，是**结构**：上游是给开发者用的工作台，小克只在外面套了一层（底部五栏、配色、我们自己的四页），一进二级页面就原样露出上游：信息密、开发向、和我们的页面互相重复、有的和角色配色直接打架。

## 看到的问题

### 一、和我们的页面重复（同一件事两个入口、两种样子）
| 上游 | 我们的 | 说明 |
|---|---|---|
| 设置 → 通用 → 深浅 | 我的 → 外观 | 两处都能改深浅 |
| 设置 → 用量与耗电、整页「用量」 | 我的 → 用量（跳的就是上游整页） | 用量有三个入口 |
| 设置 → 接口与型号 | 我的 → 接口与账户（跳过去） | 能接受，但上游页里大量开发选项 |
| 侧栏：新对话 / 对话 / 项目 / 脉络 / 定时任务 / 更多 | 底部五栏 + 顶栏新对话 | 侧栏和底栏两套导航 |
| 整页「项目」 | 角色页 | 三个角色在上游眼里是三个「项目」，项目页把它们连同目录路径（`…/workspace/roles/xiaoke`）一起列出来 |

### 二、和角色配色、人设打架
- 设置 → 通用 → **强调色**（9 个色块）：配色已经跟着角色走，选了也被盖住，等于一个失效的选项。
- 设置 → 通用 → **头像与昵称**：显示「C / cccodroid」，和小克这个产品对不上。
- 上游整页打开时**顶栏还是聊天的顶栏**（头像、角色名、新对话），页面标题在它下面，看着像两层；底栏又被藏掉，只能靠返回键出来。
- 上游的提示还在用「Claude」称呼对面（「这一轮 Claude 能用的全部东西」「Claude 行为」），伴侣的语境里应该是「她」或角色名。

### 三、开发向的选项摆在明面上
设置里大部分是工作台选项：Shizuku、执行方式、静态程序兼容、内存管家、最多同时跑几个会话、顶栏按钮排布、消息下面的按钮、附加目录、输出风格、工作岛、运行状态的原始诊断……
主人 11-02 定过「聊天页上的工作台元素一直摆着」，但设置页里这些是**配置**，不是工作台本身，绝大多数一辈子不会点。

### 四、排版
- 设置每一类都是一长串「标题 + 两行小字 + 控件」，说明文字截断成两行半，密度很高，没有分组层次。
- 整页（项目、定时任务、用量）卡片和我们的卡片圆角、留白、字号都不一样，像两个 App。
- 「脉络」的新手引导气泡（「第一次来？点右上『怎么看』」）离开脉络页后还挂在别的页面上（截图里帮助页、用量页右下角）。

## 建议的方向（待主人定）

把「我的」做成伴侣 App 自己的设置，上游的完整设置退到「我的 → 开发者 → 全部设置」原样保留：

- **我的**（我们画）：账号与接口（三个人各自用什么：小克的 Claude 账户、哈基米的 Google、小鱼的 DeepSeek Key）／外观（深浅、字体、字号、动效、音效）／通知／用量（三个人分开看）／更新与关于。
- **开发者**（二级入口）：终端、文件、git、组件、插件、定时任务、项目、脉络、全部设置——点进去就是上游原样，不改上游代码。
- 上游里和我们冲突的少数几项直接藏掉（强调色、风格、头像昵称），其余不动，同步上游时不冲突。
- 上游整页打开时盖住聊天顶栏、自带返回，看着是一层。
- 侧栏只留「对话」列表（按角色分组），其余入口去掉，导航统一走底栏。

这样改，二级页面的「重复」和「打架」基本都消掉；开发向的东西还在，只是不挡路。
