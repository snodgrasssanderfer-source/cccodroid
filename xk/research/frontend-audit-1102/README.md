# 前端走查（云端）：上游的设置页和二级页面，2026-11-02

云端会话在 `dev`（v0.2.3 之后）上起真实网关，用无头浏览器按手机宽度（390×844）把上游的设置八类、九个整页、侧栏各截了一张：`settings.jpg`、`pages.jpg`。
云端看得到排版和结构，看不到手感、真机字号、键盘弹出这些，**真机上的发现请手机上的小克接着补在后面**。

## 结论

问题主要不是零散 bug，是**结构**：上游是给开发者用的工作台，小克只在外面套了一层（底部五栏、配色、我们自己的四页），一进二级页面就原样露出上游：信息密、开发向、和我们的页面互相重复、有的和角色配色直接打架。

## 看到的问题

### 一、和我们的页面重复（同一件事两个入口、两种样子）
| 上游 | 我们的 | 说明 |
|---|---|---|
| 设置 → 通用 → 深浅 | 我的 → 外观 | 两处都能改深浅 |
| 设置 → 用量与耗电、整页「用量」 | 我的 → 用量（跳的就是上游整页） | 用量有三个入口 |
| 设置 → 接口与型号 | 我的 → 接口与账户（跳过去） | 能接受，但上游页里大量开发选项 |
| 侧栏：新对话 / 对话 / 项目 / 脉络 / 定时任务 / 更多 | 底部五栏 + 顶栏新对话 | 侧栏和底栏两套导航 |
| 整页「项目」 | 角色页 | 三个角色在上游眼里是三个「项目」，项目页把它们连同目录路径（`…/workspace/roles/xiaoke`）一起列出来 |

### 二、和角色配色、人设打架
- 设置 → 通用 → **强调色**（9 个色块）：配色已经跟着角色走，选了也被盖住，等于一个失效的选项。
- 设置 → 通用 → **头像与昵称**：显示「C / cccodroid」，和小克这个产品对不上。
- 上游整页打开时**顶栏还是聊天的顶栏**（头像、角色名、新对话），页面标题在它下面，看着像两层；底栏又被藏掉，只能靠返回键出来。
- 上游的提示还在用「Claude」称呼对面（「这一轮 Claude 能用的全部东西」「Claude 行为」），伴侣的语境里应该是「她」或角色名。

### 三、开发向的选项摆在明面上
设置里大部分是工作台选项：Shizuku、执行方式、静态程序兼容、内存管家、最多同时跑几个会话、顶栏按钮排布、消息下面的按钮、附加目录、输出风格、工作岛、运行状态的原始诊断……
主人 11-02 定过「聊天页上的工作台元素一直摆着」，但设置页里这些是**配置**，不是工作台本身，绝大多数一辈子不会点。

### 四、排版
- 设置每一类都是一长串「标题 + 两行小字 + 控件」，说明文字截断成两行半，密度很高，没有分组层次。
- 整页（项目、定时任务、用量）卡片和我们的卡片圆角、留白、字号都不一样，像两个 App。
- 「脉络」的新手引导气泡（「第一次来？点右上『怎么看』」）离开脉络页后还挂在别的页面上（截图里帮助页、用量页右下角）。

## 建议的方向（待主人定）

把「我的」做成伴侣 App 自己的设置，上游的完整设置退到「我的 → 开发者 → 全部设置」原样保留：

- **我的**（我们画）：账号与接口（三个人各自用什么：小克的 Claude 账户、哈基米的 Google、小鱼的 DeepSeek Key）／外观（深浅、字体、字号、动效、音效）／通知／用量（三个人分开看）／更新与关于。
- **开发者**（二级入口）：终端、文件、git、组件、插件、定时任务、项目、脉络、全部设置——点进去就是上游原样，不改上游代码。
- 上游里和我们冲突的少数几项直接藏掉（强调色、风格、头像昵称），其余不动，同步上游时不冲突。
- 上游整页打开时盖住聊天顶栏、自带返回，看着是一层。
- 侧栏只留「对话」列表（按角色分组），其余入口去掉，导航统一走底栏。

这样改，二级页面的「重复」和「打架」基本都消掉；开发向的东西还在，只是不挡路。

## 美术需要补的（方向定了再出清单）

## 真机补充（手机上的小克）

手机上的小克，2026-11-02 上午。真机 iQOO Neo11，Android 16，界面 CSS 宽 360、高 774（键盘弹起 458），设备像素比 4。App 是 v0.2.2 加临时装的 PR #3/#4/#5（这一节只看前端，和那几个 PR 无关）。

**怎么走的**：经 WebView 调试口（`~/.webdebug`）逐页打开，每页从顶到底分屏截图（原尺寸截、ffmpeg 缩到 360 宽），同时量：冲出屏幕的元素、显示省略号的文字、小于 32px 的按钮、小于 11px 的字、聊天顶栏和底栏露没露着；再按一下返回看落到哪。走查期间写请求全拦、外壳动作全暂停，本地偏好开跑前后逐项对比无变化。截图在 `device/`，聊天和私人内容用灰块盖掉。

### 设置（八类）

截图：`device/s1-settings-general-provider.jpg`、`s2-settings-claude-run.jpg`、`s3-settings-device-update-usage.jpg`。打开方式：我的 → 更多设置（或侧栏底部账户行）→ 各分类。

1. **「通用 → 顶栏按钮」整块失效。** 五个按钮（文件浏览器、终端、浏览器、命令面板、新会话）各有「常驻 / 收进 / 隐藏」，共 15 个选项，但 `xk.css:165` 藏了 `#tb-tools`、`#btn-more`，`#tb-pins` 也不显示（调试口读到三者都是 `display:none`）。怎么选界面都不变。
2. **同一个值两个控件、两个地方。** 「接口与型号 → 上下文压缩线」（滑杆）和「Claude 行为 → 自动压缩窗口（token）」（输入框）写的都是 `autoCompactWindow`（`app/12-model-caps.js:554`、`:559`）。
3. **两个动效开关。** 「通用 → 界面动效」（上游，跟随系统/开/关）和「我的 → 动效」（`xk.motion`），用户分不清各管什么。
4. **「接口与型号」写着「当前在用：DeepSeek」**，而主人正在和用 Claude 账户的小克聊。上游只有一个「全局在用」，不知道三个角色各绑一家；和新对话输入框下显示 deepseek-flash 同一个根子（#9 三.4）。
5. **两条要紧的真机状态埋得太深：**
   - 「后台与并行」顶上黄字：「检测到 小克 在后台被系统冻结过 3 次（最近一次约 16 秒，2026/11/1 23:41:19）」，附 vivo 上允许后台高耗电的路径。这直接关系夜里写日记、空闲整理记忆能不能跑。
   - 「设备与权限」：「Shizuku 已安装，但服务没在运行（重启手机后需要在 Shizuku 里重新启动）」。手机上的小克当天早上用 `priv` 碰壁就是这个原因。
   两条都只有翻进对应分类才看得到。
6. **说明文字一律截成两行加省略号，手机上没有展开的办法。** 例：「敏感操作再确认」「空闲压缩」「静态程序兼容」「执行方式」的说明都被截断，关键条件（「只对 Claude 账户和 Anthropic API Key 生效」之类）看不全。八类里有 15 处截断。
7. **内部名直接露给用户**：权限模式显示 `bypassPermissions · 全部…`；「工作岛（ColorOS 灵动岛）」在 vivo 上照样列出。
8. **「更新」里两个红色「卸载」**（开发工具包、Claude Code）紧挨着「校验」「本地文件…」「版本…」，同一行、同样大小，容易误点。
9. **分段按钮放不下被截**：「默认 / 跟随系统 / 自选…」、模型下拉「deepseek-flash · DeepSe…」。
10. 「更新」显示「小克 0.2.2 已是最新」，上次检查 08:17:47；dev 已出 0.2.3（是否发布了 Release、更新源是否认得，待查）。

返回键：在任一分类里按返回，回到设置的分类列表，再按回到原处——这一层是对的。

### 键盘

用真实触摸（调试口 `Input.dispatchTouchEvent`）点输入框，让输入法弹出来，再量。截图：`device/k1-chat-keyboard-up.jpg`（聊天内容已盖）、`k2-palette-keyboard-up.jpg`。

11. **键盘本身不挡输入框**：WebView 跟着缩到 458 高，聊天输入框、命令面板、设置的白名单、对话页搜索、记忆页搜索被点中时都还在可见区。
12. **但键盘弹起时空间分配很差。** 底栏（聊天/角色/记忆/日记/我的，约 55px）仍顶在键盘上面，输入框下两行（项目·账户·型号·权限、耗时·token）也照占，**留给消息的只剩约 200px（三行字）**，思考中的小人还压在上面。建议：键盘弹起时收起底栏，输入框下两行合成一行或收起。
13. **命令面板夹在顶栏和输入框之间**，标题写「46 项」，一屏只看得到三四条。
