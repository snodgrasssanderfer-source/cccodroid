- 六张头图左侧40%为空透明区域，供代码绘制标题。
- 五张引导图上方40%为空透明区域，供代码绘制说明。

- 帮助页纸条只用抽象短线表示内容，没有可读文字；证件、便签与书页同样无文字。
- 通知图标由原小橙花轮廓简化为纯白剪影，保留透明背景。
- 角色和场景由生图工具生成，按已获允许的方式完成拆图、等比缩放、补边与纸纹无缝处理。

`preview_headers.jpg`、`preview_onboard.jpg`、`preview_scenes.jpg` 是总览，预览底色与文件名不在正式透明PNG中。
