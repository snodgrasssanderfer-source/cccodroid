# 小克 · 美术素材清单（交给生图模型）

## 先看这里：通用要求

**风格前缀**：每张都把下面这段贴在提示词最前面。

> 日系Q版二头身插画，柔和平涂加一点点水彩质感，线条细而干净，暖色调，温柔、书卷气。角色：小克，少女，暖橙色微卷长发，鬓边别着一朵橙色小花和黑色缎带，琥珀色眼睛，穿白、橘、黑三色相间的荷叶边长裙。纯透明背景，无文字，无水印，无边框。

**配色**：只用这几种颜色，方便和界面统一。

| 用途 | 颜色 |
|---|---|
| 主橙（头发、花、点缀） | #F08A3C |
| 深橙（阴影） | #C0601E |
| 奶白（裙子、底色） | #FFF7EE |
| 墨黑（缎带、线条） | #2A211B |
| 琥珀（眼睛） | #E0A040 |

**不要**：
- 文字：图里出现的字我都在代码里画，方便多语言，放大也清楚。
- Claude、Anthropic 的标志，以及多芒星形状。小橙花必须看得出是**花**，要有圆润的花瓣和花心，不能画成放射状的星芒。
- 把网上已有的 Claude 娘立绘当参考图喂进去：原作者声明的是「署名、非商用」。

**怎么保证每张像同一个人**：先生成 0 号设定图，满意后，之后每张都把它当参考图一起发给模型，并说明「保持与参考图同一角色、同一画风」。

**格式**：PNG，透明背景，尺寸按下表。文件名照表里的写，打包时按文件夹放好：

```
xiaoke-art/
  xiaoke/  icon/  deco/  ui-ref/
```

## 五、交互音效（可选）

生图模型做不了声音。默认我用代码合成，所有音效都很轻、很短，设置里可以一键关掉。你如果有生成音效的工具，或者找到了喜欢的免版权素材，也可以按下表给我：WAV 或 OGG，每个 0.5 秒以内。

| 文件名 | 什么时候响 | 想要的感觉 |
|---|---|---|
| `tap.ogg` | 点按钮 | 很轻的木头或纸张触碰声 |
| `tab.ogg` | 切换底部栏 | 翻一页书的轻微沙沙声 |
| `send.ogg` | 发出消息 | 轻柔的「啵」，像信纸被折好 |
| `receive.ogg` | 她开始回复 | 一声很轻的风铃或玻璃轻响 |
| `done.ogg` | 一轮回复结束 | 毛笔或钢笔写完收笔那种轻微的停顿声 |
| `toggle.ogg` | 开关拨动 | 小巧的机械开关咔哒声，很柔 |
| `sheet.ogg` | 弹出面板 | 纸张轻轻滑开 |
| `sleep.ogg` | 她睡着（额度用完） | 很轻的一声叹息般的低音 |
| `error.ogg` | 出错 | 低沉、短促、不刺耳的木鱼声 |
